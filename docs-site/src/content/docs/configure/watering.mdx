## 基本の潅水

<ManualVisual kind="output-link" label="INASの潅水機器から弁を通り、選んだ畝へ水が届く基本の潅水経路" />

| 画面の項目 | 決めること | 最初の目安 |
|---|---|---|
| 水やりする場所 | どの接続口・弁・畝へ水を送るか | 現場のラベルと照合 |
| 実行時刻 | 何時何分に始めるか | 見守れる昼間 |
| 水やり時間 | 何秒間、水を出すか | 1〜5秒から |
| 土の水分条件 | どの値以上なら見送るか | 乾湿を実測してから |
| 分割潅水 | 水を出す・休むを何回繰り返すか | 最初は無効 |

## <span className="manual-title-icon manual-title-icon--procedure" aria-hidden="true"></span>実行時刻と水やり時間

<ManualVisual kind="watering-schedule" label="朝6時30分に20秒間の水やりを実行する予定の略図" />

1つの予定には、開始時刻と水を出す時間を設定します。複数回に分けたい場合は、朝・昼・夕など必要な時刻だけ追加します。最初の試験は、現場で見守れる時刻に1件だけ作ります。

:::caution[保存直後に水が出る設定ではありません]
設定した時刻と安全条件がそろったときに動きます。すぐに試したい場合も、まず短い試験時間を設定し、現場で水を止められる状態にしてください。
:::

## <span className="manual-title-icon manual-title-icon--procedure" aria-hidden="true"></span>分割潅水

<ManualVisual kind="split-watering" label="10秒水を出して20秒休む動きを3回繰り返す分割潅水の時間図" />

分割潅水は、「水を出す時間」と「休む時間」を繰り返します。たとえば **10秒出す → 20秒休む** を3回にすると、実際に水が出る合計は30秒、最初から最後までは70秒です。

- 水が出る合計: 10秒 × 3回 = **30秒**
- 途中で休む合計: 20秒 × 2回 = **40秒**
- 最初から最後まで: **70秒**

:::caution[通常の水やり時間とは足しません]
分割潅水を有効にしている間は、分割の「出す時間 × 回数」が使われます。通常の水やり時間をさらに足すことはありません。
:::

## <span className="manual-title-icon manual-title-icon--check" aria-hidden="true"></span>土壌水分センサーで見送る

<ManualVisual kind="moisture-threshold" label="土の水分が基準より低ければ水やりし、高ければ水やりを見送る判断図" />

設定した時刻になっても、土が十分湿っていれば水やりを見送れます。基準は製品の初期値だけで決めず、同じセンサーで乾いた土と十分湿った土を測ってから設定します。

値が急に変わる、ずっと同じ、濡らしても変化しない場合は、自動運転を始めずセンサーの設置と状態を確認してください。

## <span className="manual-title-icon manual-title-icon--check" aria-hidden="true"></span>保存後の確認

1. 「保存して機器へ反映」を押します。
2. 機器画面で、新しい設定を受け取った表示を確認します。
3. 次回予定の時刻、水やり時間、水分条件を読み直します。
4. 人が見ている状態で1〜5秒だけ試します。
5. 水の行き先と漏れがないことを確認し、実際の流量に合わせて少しずつ延ばします。

設定キーや機器内部の判定を確認する技術担当者は、[設定項目の技術リファレンス](/configure/settings-reference/)を参照してください。
