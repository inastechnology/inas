すべての階層を使う必要はありません。小規模なら圃場へ直接機器を置き、複数のハウスや畝がある場合だけ分割します。

## 圃場を作る

1. 「圃場」を開き、新規作成します。
2. 表示名、所在地、時刻の地域を確認します。
3. 作物・品種・栽培方法を登録します。
4. 必要な区画・畝を作ります。
5. 設置ビューで現場に近い位置へ配置します。

## <span className="manual-title-icon manual-title-icon--procedure" aria-hidden="true"></span>機器を接続して自動認識させる

<DeviceConnectionGuide />

Local Hubへ直接つなぐ場合も、Edge Gatewayを経由する場合も、利用者が新規登録画面で機器番号を入力することはありません。接続した機器が最初の状態を送ると、受け取り役が見つけて一覧へ反映します。

:::note[最初は「確認待ち」でも正常です]
知らない機器が勝手に運転を始めないよう、自動認識された直後は確認待ちになる場合があります。現物の機器番号と設置場所を確認してから承認してください。
:::

## 承認後にそろえる3つの情報

| 画面で設定すること | 例 | 目的 |
|---|---|---|
| 分かりやすい名前 | 育苗ハウス潅水機 | 一覧から現物を見つけやすくする |
| 設置場所 | 第1圃場 / ハウスA / 畝2 | 測定値と作業を同じ場所へ結び付ける |
| 水やりの行き先 | 接続口1 → ハウスA東側 | 画面表示と実際の配管を一致させる |

:::caution[現場のラベルを基準にします]
筐体、接続口、画面の名前をそろえてください。「どの線がどの畝へ水を送るか」を、現場と画面の両方から追える状態にします。
:::

## <span className="manual-title-icon manual-title-icon--check" aria-hidden="true"></span>接続できたことを確認する

**機器一覧に新しい機器が表示されれば、接続成功です。** この時点で「接続」と「自動認識」は完了しています。名前や設置場所は、そのあと落ち着いて設定できます。

表示されない場合は、複数の機器を同時に触らず、最初の1台だけで電源、利用するネットワーク、Local HubまたはEdge Gatewayの状態を順に確認します。
