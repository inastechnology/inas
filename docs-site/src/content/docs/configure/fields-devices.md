---
title: 圃場とデバイス
description: 圃場の階層を作り、デバイスを正しい場所と機能へ関連付けます。
---

デバイスを登録する前に、現場と同じ順序で圃場の階層を作ります。測定値・作業・潅水先が同じ場所へ結び付くため、あとから探しやすくなります。

## 圃場の階層

```text
圃場
├─ 区画
│  ├─ 畝・ベッド
│  └─ 設置ポイント
└─ 圃場全体に属する設備
```

すべての階層を使う必要はありません。小規模なら圃場へ直接deviceを置き、複数houseや畝がある場合だけ分割します。

## 圃場を作る

1. 「圃場」を開き、新規作成します。
2. 表示名、所在地、timezoneを確認します。
3. 作物・品種・栽培方法を登録します。
4. 必要な区画・畝を作ります。
5. 設置ビューで現場に近い位置へ配置します。

## デバイスを登録する

1. 「デバイス」から追加を選びます。
2. F/Wと一致するdevice kindを選びます。
3. F/Wの `device_id` を入力します。大文字・小文字・hyphenを含め完全一致させます。
4. 設置する圃場・区画・畝・pointを選びます。
5. outputへ接続した負荷種別と名前を登録します。
6. 保存後、対象deviceの詳細で最新状態を確認します。

## 一致させる3つの情報

| 情報 | 例 | 不一致時の問題 |
|---|---|---|
| device kind | `WTR` | 設定項目・action・pin contractが合わない |
| device ID | `WTR-001` | Hubが別deviceとして扱う |
| output inventory | `D4 / irrigation / pump` | 画面の表示と実配線がずれる |

:::caution[ラベルを基準にする]
筐体、端子、Hubのoutput名を一致させてください。「どの線がどの畝へ水を送るか」を、現場と画面の両方から追跡できる状態にします。
:::

## 登録後の確認

- device detailにF/W versionが表示される。
- 最終受信時刻が更新される。
- device kindが実機と一致する。
- latest statusに `config_received` が表示される。
- 設置ビューからdevice detailへ移動できる。
- 潅水outputの接続先と現場ラベルが一致する。

次に[潅水設定](/configure/watering/)または各deviceのsensor設定を行います。
