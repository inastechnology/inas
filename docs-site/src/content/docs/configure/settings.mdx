## <span className="manual-title-icon manual-title-icon--procedure" aria-hidden="true"></span>個人設定

圃場一覧右上の「個人設定」を開きます。ここで変えた内容はログイン中の自分にだけ適用され、圃場や機器の動作は変わりません。

  <article><b>1</b><div><h3>タイムゾーン</h3><p>カレンダーと記録時刻を表示する地域です。日本で使う場合は「Asia/Tokyo」を選びます。</p></div></article>
  <article><b>2</b><div><h3>日付形式</h3><p>日付の見せ方だけを選びます。記録される内容や予定日は変わりません。</p></div></article>

## <span className="manual-title-icon manual-title-icon--procedure" aria-hidden="true"></span>圃場と機器の設定

圃場の名前・区画・畝は「圃場」、機器の名前・設置場所・水の行き先は「機器」から変更します。機器番号を入力して新規登録するのではなく、接続して自動認識された機器を開いて設定します。

  <ManualVisual kind="field-layout" label="圃場の設置ビューで畝と機器の位置を設定する略図" compact={true} />
  <span aria-hidden="true">→</span>
  <ManualVisual kind="output-link" label="機器の接続口と実際の弁や畝を結び付ける略図" compact={true} />

| 設定する場所 | 主な項目 | 確認する現物 |
|---|---|---|
| 圃場の基本情報 | 圃場名、所在地、作物・品種 | 現場で使う呼び方 |
| 設置ビュー | 区画、畝、機器、設備の位置 | 実際の位置関係 |
| 機器の概要 | 表示名、設置する圃場・畝 | 本体の機器番号 |
| 水やりルート | 接続口、弁・ポンプ、水が届く畝 | 配線・配管のラベル |

詳しい接続順は[圃場とデバイス](/configure/fields-devices/)を参照してください。

## <span className="manual-title-icon manual-title-icon--procedure" aria-hidden="true"></span>機器の「動作設定」

機器一覧から対象の潅水機器を開き、「動作設定」を選びます。ここは**実際の水やりに影響する設定**です。保存前に、機器名と水の行き先をもう一度確認してください。

  <figcaption>上から「行き先」「時刻と時間」「土の水分」「分割」の順に確認すると、設定漏れを防げます。</figcaption>
</figure>

<div className="setting-explain-list">
  <article><b>1</b><div><h3>現在の水やりルート</h3><p>どの接続口から、どの弁・ポンプを通り、どの畝へ水が届くかを設定します。</p></div></article>
  <article><b>2</b><div><h3>潅水予約</h3><p>水やりを始める時刻と、水を出す秒数を決めます。最初は見守れる時刻に1〜5秒で試します。</p></div></article>
  <article><b>3</b><div><h3>土の水分条件</h3><p>指定した値以上に湿っているとき、水やりを見送るための基準です。乾いた土と湿った土を実測して決めます。</p></div></article>
  <article><b>4</b><div><h3>分割潅水</h3><p>「水を出す」「休む」を何回繰り返すか決めます。有効中は通常の水やり秒数へ加算されません。</p></div></article>
  <article><b>5</b><div><h3>保存して機器へ反映</h3><p>保存後、機器が新しい内容を受け取った表示と次回予定を確認して、短時間の試験を行います。</p></div></article>
</div>

:::caution[設定しただけで現場確認を終えません]
水やりに関わる値を変えたら、人が見ている状態で短く試し、水の行き先、漏れ、停止方法を確認します。
:::

## 管理者だけが変更する設定

AI、通知、外部サービス、Hub本体の接続状態は「アプリ設定」にあります。通常の作業者が変更する必要はありません。管理者向けの全項目は[アプリ設定の技術ガイド](/technical/app-settings/)へ分けています。
