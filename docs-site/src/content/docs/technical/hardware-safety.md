## 電気

- XIAO ESP32S3のGPIOは3.3Vです。12VをGPIOや `VBUS` へ接続しません。
- 12V構成では、安定化した5VをXIAOの `VBUS` へ供給します。
- ポンプや電磁弁をGPIOから直接駆動しません。定格に合うMOSFET・relay・driverを使います。
- motor・solenoidなどの誘導負荷にはflyback protectionを設けます。
- 初回通電は電流制限付き電源を使い、XIAOを挿す前に電源電圧と極性を測定します。
- GNDを共通化し、電源線には用途と電圧を表示します。
- 最大電流、起動電流、電線サイズ、fuse、端子定格を負荷ごとに確認します。

## 水と設備

- 制御基板・電源・端子を防滴または防水筐体へ収めます。
- ケーブル引込部にstrain reliefとcable glandを設けます。
- 最初の潅水試験は、配管を外すか、排水を管理できる容器内で行います。
- 遠隔操作の前に、現場で停止手段と手動遮断弁を確認します。
- 長時間の連続運転を防ぐため、設定値と物理流量の両方から最大水量を見積もります。
- 漏水時に電源設備へ水が流れ込まない位置関係と排水経路を確保します。

## ソフトウェア上の安全

- 起動時潅水モードは敷設時の導通試験だけに使い、試験後は無効にします。
- 設定変更後は、対象device IDと次回起動時刻を確認します。
- OTAは少数のデバイスで確認してから段階的に適用します。
- 管理APIのtokenをbrowserやチャットへ貼り付けません。
- 通信断、Hub停止、時刻未同期、古い設定が残る場合のfail-safe動作を機種ごとに試験します。

## 受入試験

1. 負荷を外した状態で電源電圧と極性を測る。
2. 電流制限を設定し、制御基板だけを起動する。
3. 実負荷の代わりに安全な試験負荷で出力を確認する。
4. 手動遮断が機能することを確認する。
5. 少量・短時間の通水を行い、漏れと最大流量を確認する。
6. 電源再投入、通信断、Hub停止時に意図しない出力が出ないことを確認する。
7. 試験用modeを無効にし、変更記録を残す。

一般利用者へ渡す説明は、[安全上の注意](/start/safety/)の範囲に留めます。
