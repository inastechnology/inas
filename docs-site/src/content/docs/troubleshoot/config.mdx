Hubで設定を保存した直後に、機器の動作が変わるとは限りません。機器が次に通信し、設定を受け取ってから動作へ反映します。

## Hub画面で確認する

1. 「機器一覧」から対象の機器を開きます。
2. 「動作設定」で、保存した値が画面に残っていることを確認します。
3. 「概要」を開き、「動作確認」の「設定の受信」を確認します。
4. 「確認待ち」の場合は、同じ画面の「次回起動」まで待ちます。

## 表示ごとの判断

### 保存した値が画面から消える

Hubへの保存が完了していません。画面にエラーが出ていないか確認し、対象の機器を開き直してから、1項目だけ変更して保存します。

**確認する理由:** 機器へ送る前に、Hubが変更内容を保持できている必要があるためです。

### 「機器と通信」が未取得

設定の問題より先に、機器の通信を復旧します。[デバイスがオフライン](/troubleshoot/device-offline/)の手順を確認してください。

**確認する理由:** 通信できない機器は、新しい設定を受け取れないためです。

### 「設定の受信」が確認待ち

「次回起動」に時刻が表示されていれば、その時刻まで待ちます。機器を安全に再起動できる場合は、一度だけ再起動してから画面を更新します。

**確認する理由:** 省電力機器は、休止中にはHubから設定を受け取れないためです。

### 「設定の受信」が受信済み

設定は機器まで届いています。それでも動作が変わらない場合は、現在値、予約時刻、しきい値、出力先の順に確認します。

**確認する理由:** ここから先は通信ではなく、動作条件または接続した設備の問題に切り替わるためです。

## 反映を確認する

1. 保存した値をスクリーンショットで残します。
2. 「設定の受信」が「受信済み」になるまで待ちます。
3. 「現在の判断」に表示される予約やしきい値が変わったことを確認します。
4. 次の起動後も同じ値が表示されることを確認します。

<Aside type="caution" title="短時間に保存や再起動を繰り返さない">
機器はWi-Fiへ接続したあと、設定を受け取って保存するまで少し時間がかかります。数秒ごとに電源を切ったり、複数の値を続けて変更したりせず、1回の通信が完了するまで待ってください。
</Aside>

管理担当者が受信データを調査する場合は、機器の「保守・管理」にある「管理者向けの技術データ」と[機器設定の技術資料](/reference/runtime-config/)を参照してください。
