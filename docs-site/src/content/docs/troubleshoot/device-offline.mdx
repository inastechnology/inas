まずHub画面で、機器がどこまで通信できたかを確認します。コマンドや通信トピックを調べる必要はありません。

## Hub画面を開く

1. Hubの「機器一覧」を開きます。
2. オフラインになっている機器を選びます。
3. 「保守・管理」タブを開きます。
4. 見出しの右にある「？」を押し、表示された案内を左から順に確認します。

## 1. 「Hubが最後に確認」を見る

ここには、Hubが機器から状態を受け取った時刻が表示されます。

- 時刻が最近まで更新されている: その時刻までは、機器の電源、Wi-Fi、Hubへの接続が成功しています。
- 時刻が古い: 表示時刻より後に、電源が切れた、Wi-Fiが届かなくなった、または機器が休止した可能性があります。
- 「未取得」: Hubはこの機器から一度も状態を受け取っていません。電源と初期設定から確認します。

**確認する理由:** 最後に成功した時刻を起点にすると、正常だった設定をむやみに変更せずに済みます。

## 2. 「Hubへの接続」を見る

「接続を確認」と表示されていれば、機器は少なくとも一度Hubの入口まで到達しています。「保守・管理」の「通信・接続履歴」で、成功した時刻と、その後に接続を終了した時刻を確認できます。

「Hubとの接続を終了」は、必ずしも故障ではありません。電池や省電力で動く機器は、状態を送ったあと次の起動まで通信を休みます。

**確認する理由:** Wi-Fiへの接続と、Hubが機器を受け入れたことは別の段階です。接続成功の記録があれば、Wi-Fi名やHubの接続先はその時点では正しかったと判断できます。

## 3. 「次回の通信予定」を見る

省電力機器では、次に起動して状態を送る予定時刻が表示されます。その時刻を過ぎるまでは、接続終了の記録だけを見て異常と判断しません。

- 予定時刻より前: 機器が休止中の可能性があります。そのまま待ちます。
- 予定時刻を過ぎても最終確認が更新されない: 機器の電源とWi-Fiの電波を確認します。
- 「未取得」: まだ状態を受信していないか、常時接続する機器です。

**確認する理由:** 正常な省電力動作と、本当の通信停止を見分けるためです。

## 接続記録がない場合

機器の初期設定画面を開き、画面上部に表示される開始理由を確認します。

次の順に1項目ずつ確認します。

1. 機器の電源が入り、異常な発熱や再起動の繰り返しがない。
2. 初期設定画面に、使用するWi-Fi名が表示されている。
3. 機器をHubと同じ場所へ近づけて起動すると接続できる。
4. Hubの「保守・管理」にある「通信・接続履歴」に、接続成功の記録が追加される。
5. 「Hubが最後に確認」の時刻が更新される。

<Aside type="caution" title="一度に複数の設定を変えない">
Wi-Fi名、パスワード、設置場所を同時に変えると、どの変更で直ったのか分からなくなります。現在の画面を撮影し、1項目ずつ変更してください。
</Aside>

## 復旧したことを確認する

次の3点がそろえば、Hubまでの通信は復旧しています。

- 「Hubが最後に確認」が現在時刻付近へ更新された。
- 「通信・接続履歴」に新しい成功記録が追加された。
- 次回の通信後も最終確認が更新された。

管理担当者がさらに調査する場合は、[ネットワークの技術資料](/technical/networking/)を参照してください。一般ユーザーが通信トピックやサーバーのログを確認する必要はありません。
