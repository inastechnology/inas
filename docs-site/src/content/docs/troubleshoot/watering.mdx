水が出ないときは、設定を変更する前にHubが表示している「現在の潅水判断」を確認します。通信、予約条件、出力先、水路の順に見ると、止まっている場所を切り分けられます。

## 「概要」を開く

1. Hubの「機器一覧」から対象の水やり機を開きます。
2. 「概要」を選びます。
3. 「現在の潅水判断」と「動作確認」を画面の上から確認します。

## 画面で確認する内容と理由

### 次の潅水

期待する予約時刻と一致しているか確認します。違う場合は「設定を変更」から予約を見直します。

**確認する理由:** 機器が認識している次回時刻が違えば、待っても期待した時刻には動かないためです。

### 現在の土壌水分としきい値

現在の土壌水分がしきい値より高い場合は、土が十分湿っていると判断して潅水を見送ることがあります。

**確認する理由:** 予約時刻になっても、安全条件や水分条件によって水を出さない動作は正常だからです。

### 現在の潅水状態

「待機中」「潅水中」など、最後に受信した状態を確認します。表示が古い場合は、先に[デバイスがオフライン](/troubleshoot/device-offline/)を確認します。

**確認する理由:** 古い状態のままでは、現在の機器判断と画面表示が一致しないためです。

### 動作確認

「機器と通信」「設定の受信」「時刻合わせ」「出力先」を左から順に見ます。

- 機器と通信が未取得: 通信を復旧します。
- 設定の受信が確認待ち: 次回起動まで待ちます。
- 時刻合わせが確認待ち: 予約時刻を判断できないため、次回通信を待ちます。
- 出力先が0系統: 「動作設定」でポンプやバルブの接続先を設定します。

**確認する理由:** 最初に確認待ちになる項目より後の設備を調べても、原因を解決できないためです。

## Hub画面が正常な場合

画面上の4項目が正常なら、実際の設備を安全に確認します。

1. 手動弁が閉じていない。
2. タンクに水があり、吸い込み口やフィルターが詰まっていない。
3. ポンプまたはバルブの電源が入っている。
4. ホースの折れ、外れ、凍結、漏れがない。
5. 機器とポンプ・バルブの接続が抜けていない。

<Aside type="danger" title="通電中の配線作業はしない">
配線の差し直しや電圧測定が必要な場合は、設備の電源を切り、施工・保守を担当する人へ依頼してください。水がかかった機器には触れないでください。
</Aside>

## 復旧したことを確認する

- 「現在の潅水状態」が新しい時刻の情報へ更新された。
- 試験後にポンプまたはバルブが動き、実際に水が流れた。
- 次回起動後も「動作確認」の4項目が正常に表示された。
- 試験のために変更した予約や強制動作を通常の設定へ戻した。

管理担当者が機器内部の判断を調査する場合は、「保守・管理」の「管理者向けの技術データ」と[機器の技術資料](/devices/wtr/)を参照してください。
