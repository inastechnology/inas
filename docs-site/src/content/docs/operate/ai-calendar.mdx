年間栽培カレンダーは、定植単位の栽培基準、作業候補、施肥履歴、実施記録をまとめる画面です。AIによる作り直しは現在の計画を直接上書きせず、変更案を作成します。利用者が現在の内容と比較し、取り入れる案だけを確定します。

## 年間栽培カレンダーを開く

1. 「圃場」から対象圃場を開きます。
2. 「栽培」で対象の作物・定植を選びます。
3. 「年間栽培カレンダー」を開きます。
4. 上部の「圃場の作業」と「作物別の栽培計画」を切り替えます。

「圃場の作業」は全作物の作業状態を比較する画面です。「作物別の栽培計画」では、選択した定植の栽培基準、施肥、AI計画、栽培相談を確認します。

## AIに計画の作り直しを提案してもらう

<Steps>
1. **対象の作物を確認する**

   同じ圃場に複数の定植がある場合は、「管理する作物」で対象を選びます。

2. **現在の前提を整える**

   作物・品種・定植日・栽培方式、施肥履歴、完了済み作業を確認します。AIは保存済みの情報を前提として、これからの予定に対する変更案を作ります。

3. **「AI栽培計画を作り直す」を選ぶ**

   基準日と追加要望を確認して開始します。作成中に画面を離れても処理は続き、完了すると変更案の件数が表示されます。
</Steps>

## 現在の計画と変更案を比較する

変更案は1件ずつ、左の「現在の栽培カレンダー」と右の「AIの提案」を比較します。作業期間、理由、判断条件、手順、必要時間など、変更された箇所を確認してください。

  </a>
  <figcaption>変更内容の比較画面です。「この変更を取り入れる」または「取り入れない」を選び、残りの案も同じように確認します。</figcaption>
</figure>

1. 現在と変更後の作業期間、内容、判断条件を比較します。
2. 採用する案は「この変更を取り入れる」、見送る案は「取り入れない」を選びます。
3. すべての案を判断したあと、選択内容をまとめて栽培カレンダーへ反映します。
4. 「圃場の作業」に戻り、未完了・作業中・確認待ち・完了の位置を確認します。

比較中の選択だけでは栽培カレンダーは更新されません。最後の一括反映まで進んだ時点で、採用した変更が保存されます。完了済み・作業中の記録は履歴として維持されます。

<Aside type="caution" title="AI提案は作業判断の材料です">
作物の状態、現地の天候、土壌・培地、製品ラベル、地域の基準を確認し、実施者が採否を判断してください。農薬や肥料の使用量・回数は、画面の提案だけで確定しません。
</Aside>

日々の作業状態を確認する流れは[日々の確認](/operate/daily/)を参照してください。
