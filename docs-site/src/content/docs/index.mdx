## 自己調達での導入順

<ol class="journey" aria-label="INASの導入手順">
  <li>構成を理解</li>
  <li>選定・購入</li>
  <li>LANを設計</li>
  <li>PiとHubを構築</li>
  <li>デバイスを製作</li>
  <li>接続・受入試験</li>
</ol>

<CardGrid>
  <Card title="1. 機器を選定する">
    Raspberry Pi、電源、ストレージ、冷却、LAN、最初のデバイスを、購入前に確定します。
  </Card>
  <Card title="2. Raspberry Pi Hubを作る">
    OS、mDNS、Mosquitto、Hub、Cloudflare Tunnelがどこで動くかを分けて構築します。
  </Card>
  <Card title="3. デバイスを作って接続する">
    WTR・WRS・SOI・ENVの部品、配線、F/W、Wi‑Fi/MQTT、受入試験を確認します。
  </Card>
  <Card title="4. 運用を開始する">
    圃場への関連付け、潅水設定、F/W更新、日々の確認と問題の切り分けを行います。
  </Card>
</CardGrid>
