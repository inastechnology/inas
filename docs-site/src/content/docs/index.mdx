## 通常の使い始め方

<ol class="journey" aria-label="INASの導入手順">
  <li>利用方法を選ぶ</li>
  <li>Wi-Fiを確認</li>
  <li>Hubを接続</li>
  <li>機器を1台接続</li>
  <li>画面で確認</li>
  <li>圃場へ設置</li>
</ol>

<CardGrid>
  <Card title="1. Wi-Fiを準備する">
    ルーターや家電と同じように、設置場所のWi-Fi名とパスワードを確認します。
  </Card>
  <Card title="2. Hubを接続する">
    電源を入れ、画面の案内に沿って普段使っているWi-Fiへ接続します。
  </Card>
  <Card title="3. 圃場の機器を接続する">
    最初はルーターの近くで1台だけ接続し、機器一覧へ自動で表示されることを確認します。
  </Card>
  <Card title="4. 圃場で使い始める">
    接続確認後に設置場所へ移し、測定結果と潅水の状態を画面で確認します。
  </Card>
</CardGrid>

<Aside type="tip" title="このサイト内を検索できます">

</Aside>
