## 普段使うのは画面です

パソコンやスマートフォンのブラウザで、案内されたINASのアドレスを開きます。専用アプリのインストールは必要ありません。

画面では、次のことができます。

- 圃場や作物の状態を見る
- 今日の作業とこれからの予定を見る
- 測定結果や潅水の履歴を確認する
- 圃場の機器が動いているか確認する
- AIから届いた提案を確認し、採用するか判断する

<ManualVisual kind="user-screen" label="パソコンとスマートフォンでINASの画面を見る略図" />

## Hubは情報をまとめます

INAS Hubは、圃場や事務所に置く小さなコンピューターです。画面で入力した内容を保存し、圃場の機器から届いた状態をまとめます。

提供機器を利用する場合は、必要なソフトウェアを準備した状態でお届けする想定です。電源とWi-Fiをつなげばよく、内部の仕組みを設定する必要はありません。

<ManualVisual kind="hub" label="INAS Hubを中心に画面と圃場の機器がつながる略図" />

## 圃場の機器が測定と潅水を行います

センサーや潅水機器は、Hubと同じWi-Fiを使います。設定が届くと、測定や潅水を行い、その結果をHubへ返します。

最初からすべてを設置する必要はありません。まず1台を手元で接続し、画面に状態が表示されることを確認してから圃場へ設置します。

:::tip[通常利用では、難しい設定は不要です]
提供機器の利用者が用意するのは、基本的に電源、Wi-Fi名、Wi-Fiパスワード、画面を開くパソコンまたはスマートフォンです。
