## <span className="manual-title-icon manual-title-icon--prep" aria-hidden="true"></span>設置前に準備すること

<ManualNote
  id="keep-device-closed"
  title="機器を開けたり、配線を変えたりしません"
  tone="caution"
  visual="sealed-device"
  visualLabel="INAS Hubのふたと配線を工具で開けないことを示す略図"
>
  提供機器のふたを開ける、配線を付け替える、別の電源をつなぐ作業は行いません。移動や清掃の前には電源を外し、ケーブルや電源に傷があれば使用を止めます。
</ManualNote>

<ManualNote
  id="keep-equipment-dry"
  title="水がかからない高い場所へ置きます"
  tone="safe"
  visual="dry-place"
  visualLabel="雨や水しぶきを避けた高い場所へ機器を置く略図"
>
  Hubと電源は屋内の乾燥した場所へ置き、雨、結露、薬剤、直射日光を避けます。水の配管より高くし、ケーブルは足や農機に引っ掛からないよう固定します。防滴と案内された機器でも、水中や常に水が当たる場所では使えません。
</ManualNote>
