## ここまで読み進めたあなたへ

このドキュメントを開き、機器構成や配線、ネットワーク、設定まで読み進めているあなたは、便利な製品を探しているだけではないはずです。

自分の圃場で試し、観察し、失敗から学びながら、気候と人口が変わる未来にも食糧生産を続けられる、**まだ答えのない新しい農の形を探究しようとしている人**。私たちは、INASを使う人を、そのような人だと考えています。

だから、私たちはあなたを単なる「ユーザー」や「お客様」としてではなく、未来の農を一緒につくる仲間として迎えたいと思っています。

## 自動化は、いばらの道です

農は野良仕事です。暑さ、寒さ、雨、泥、水、重い資材、予定どおりには育たない作物があります。センサーは汚れ、配線は傷み、ネットワークは途切れ、ポンプやバルブはいつか故障します。画面のボタンを押せるようになっても、こうした現場の現実はなくなりません。

さらに、これからの圃場が今までと同じ環境であり続ける保証はありません。地球温暖化が進めば、より厳しい炎天下で、これまでと同じ時間、同じ方法で働くことが難しくなります。気温、雨、水、病害虫などの条件が変われば、これまで通用した栽培方法を、そのまま続けられない可能性もあります。

INASは、農の肉体労働を消し去る魔法の箱ではありません。自動化を始めれば、施工、設定、保守、異常時の切り分けという新しい仕事も生まれます。最初は手で行うより時間がかかることさえあります。

それでも自動化に取り組むのは、人が現場を見なくてよくなるためではありません。繰り返す作業と判断の過程を観測可能にし、限られた人数でも農耕を維持できるようにしながら、本当に人が見るべき変化、手を入れるべき瞬間、次の栽培を考える時間を取り戻すためです。

## 現場の外から、農を決めつけない

INASは、エアコンの効いた部屋から圃場を想像しただけで生まれたシステムではありません。開発者自身の野良仕事と機器運用の実体験を起点に、現場で困ったこと、繰り返したくなかった失敗、残しておきたかった判断を、一つずつ仕組みにしています。

もちろん、一つの圃場で得た経験が、すべての農にそのまま当てはまるとは考えていません。土、作物、気候、水、設備、経営はそれぞれ違います。だからINASを完成した正解として押しつけるのではなく、現場ごとの差を記録し、試し、更新できるオープンソースとして育てています。

不具合や不足を「現場ごとの例外」として片づけず、次に向き合うべき事実として扱います。うまくいかなかった条件まで共有し、再現し、直していくことを大切にします。

## 子どもたちの時代にも、食糧をつくり続ける

私たちが未来へ残したいものは、単なる機械やデータではありません。**環境と人口が変わっても、安定した食糧生産を続けられる農の基盤**です。

人口が減り、農を担う人も減っていくなかで、これまでと同じ人数と労力を前提にした農耕を維持できない可能性があります。炎天下で長時間働けることを前提にせず、少ない人数でも安全に圃場を見守り、必要な作業を続けられる形を、今から探さなければなりません。

新しい農の形は、必要になった日にシステムを置けば完成するものではありません。観測し、自動化し、失敗し、直し、異なる季節と環境で確かめるには時間がかかります。今の農が成り立っているうちから探究を始めることが、子どもたちの時代の選択肢を増やします。

その基盤を支える資産として、次のものも残していきます。

- 少ない人数でも安全に運用できる仕組み
- 環境の変化を観測し、栽培方法を更新するための記録
- どの設定で動き、どの条件で失敗したかという知識
- 次の人が理解し、修理し、つくり変えられる文書とコード

INASの価値は、デバイスが一度自動で動いたことだけでは測れません。子どもたちが生きる未来にも農を続け、食糧をつくれる可能性を高められたとき、このシステムは本当の意味で役に立つと考えています。

## 私たちが約束すること

INASは、完全自動や失敗ゼロを約束しません。その代わり、次の姿勢を約束します。

  </a>
  <figcaption data-scene-label="開いて直せる">失敗を隠さず記録し、普通の工具で開いて確かめ、次の人も理解して修理できる道具を目指します。</figcaption>
</figure>

- 現場の厳しさを、都合のよい宣伝文句で隠さない
- 安全と手動で止められることを、自動化の速さより優先する
- 成功だけでなく、失敗条件と制約も文書に残す
- 利用者の圃場で得た知見を、次の改善へつなげる
- 特定の人だけが扱えるブラックボックスではなく、理解し修理できる仕組みを目指す

ここまで読んだあなたとなら、自動化の難しさも含めて共有しながら、未来の農の形を一緒に探究できると信じています。
