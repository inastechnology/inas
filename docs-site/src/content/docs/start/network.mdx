Wi-Fiの名前は、スマートフォンやパソコンで接続先を選ぶ画面に表示されるものです。ルーター本体のラベルに記載されている場合もあります。

<ManualNote
  id="wifi-band-note"
  title="「2.4GHz」と表示される方を使います"
  tone="caution"
  visual="wifi-band"
  visualLabel="Wi-Fi一覧でfarm-wifi-2Gに丸、farm-wifi-5Gにバツを付けた略図"
>
  一般的なWi-Fiルーターには「2.4GHz」と「5GHz」の2種類が表示されることがあります。圃場の機器には、**2.4GHz、2G、2.4Gと書かれた方**を選びます。

  どちらか分からない場合は、ルーターの取扱説明書または管理者へ「2.4GHz側のWi-Fi名」を確認してください。
</ManualNote>

<ManualNote
  id="guest-wifi-note"
  title="来客用Wi-Fiは使いません"
  tone="caution"
  visual="wifi-guest"
  visualLabel="Wi-Fi一覧で通常のfarm-mainに丸、farm-guestにバツを付けた略図"
>
  「ゲスト」「来客用」と書かれたWi-Fiは、接続した機器同士が見えないことがあります。INAS Hubと圃場の機器には、**普段使っている通常のWi-Fi**を選びます。

  施設の管理者には「同じWi-FiにつないだINAS Hubと圃場の機器が、互いに通信できる状態にしてください」と伝えます。
</ManualNote>

<ManualNote
  id="wifi-troubleshooting"
  title="つながらないとき"
  tone="trouble"
  visual="troubleshoot"
  visualLabel="電源、Wi-Fi、入力内容、距離を虫眼鏡で順番に確認する略図"
>
  設定手順とは分けて、次の順番で原因を確認します。

  - Hubとルーターの電源が入っている
  - Wi-Fi名の選択を間違えていない
  - パスワードの大文字・小文字が合っている
  - 圃場の機器が2.4GHz側を選んでいる
  - 来客用Wi-Fiを選んでいない
  - ルーターから離れすぎていない

  改善しない場合は、設定画面のメッセージと止まった手順番号を記録してサポートへ連絡してください。Wi-Fiのパスワードは送らないでください。
</ManualNote>
