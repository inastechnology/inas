## 予定している提供状態

弊社提供Hubは、出荷時点で次の状態にする予定です。

- 検証済みの最新Hubソフトウェアをインストール済み
- `.env` とMQTT brokerを顧客向けにセットアップ済み
- systemdによる自動起動を設定済み
- 顧客IDに対応するmDNS名 `<顧客ID>.local` を設定済み
- 顧客が用意したCloudflare Access環境へ接続できる状態

正式な提供内容は、製品仕様と出荷検査方法の確定後に公開します。

## 予定している利用開始フロー

1. 出荷時の紙とemailで、顧客ID、Hub名、アクセス先を確認する。
2. Hubへ電源を入れ、初回だけ設置場所のWi‑Fiを設定する。
3. 各デバイスのsetup APを開き、2.4GHz Wi‑FiとMQTT broker `<顧客ID>.local` を設定する。
4. デバイスがWi‑FiとMQTTへ接続し、Hubに表示されることを確認する。
5. 顧客が設定したCloudflare Accessで認証し、外部からHubを使用する。

Hubソフトウェア、`.env`、MQTT brokerの構築手順はスキップできる想定です。一方、**設置場所のHub Wi‑Fiと、各デバイスのWi‑Fi/MQTT設定は現地で必要**です。
