## 自分で構築する場合

次の作業を自分で行える技術者が対象です。

- 小型コンピューターへ基本ソフトウェアを導入する
- コマンドを使ってサービスを設定する
- ルーターの管理画面を操作する
- 電子部品を選定し、配線と安全試験を行う
- 問題発生時に記録を確認して切り分ける

これらに慣れていない場合は、自己判断で配線や設定を進めず、提供機器の準備を待つか、技術者へ相談してください。

## <span className="manual-title-icon manual-title-icon--check" aria-hidden="true"></span>判断の目安

| 希望 | 選ぶ方法 |
|---|---|
| 箱から出して案内どおりに使いたい | 提供機器 |
| 内部の仕組みを意識せず、畑の管理に集中したい | 提供機器 |
| 自分で部品を選び、機能を変更したい | 自己構築 |
| ソフトウェアや電子回路の検証をしたい | 自己構築 |

自己構築を選ぶ場合は、最初に[技術構成と責務](/technical/architecture/)を読み、その後[技術者向けの全手順](/start/quickstart/)へ進みます。
