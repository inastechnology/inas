# AI に記録と写真を参照させる

専用の読み取り機能を含む Hub へ更新し、管理者が接続を設定すると、外部の AI から許可された圃場のメモ（note）、日々の記録、記録に添付した画像、保存済みのカメラ画像を参照できます。期間やキーワードで記録を絞り込み、必要な写真を確認できます。

管理者は、参照を許可する圃場と「記録」「画像」の範囲を指定します。収集用の接続では、機器の更新、設定変更、記録の追加・削除はできません。カメラ画像は保存済みの写真で、AI の取得要求による新しい撮影は行いません。

人間用の Cloudflare Access ログインを AI に代行したり、ログイン Cookie・認証コードを渡したりする必要はありません。専用の機械認証で接続します。AI アプリへ接続すると、呼び出した範囲の本文や写真がそのアプリへ渡ります。

対応版への更新と管理者による初期設定の後、「アプリ設定 → AI 接続・読み取り権限」で接続名、許可する圃場、記録・画像の範囲、有効期限を選び、Token を発行できます。秘密値は発行直後に一度だけ表示されるので、AI クライアントの認証ファイルへ保存してください。チャットへ貼り付ける必要はありません。

有効期限には「無期限」も選べます。無期限の接続は、停止するまで期限切れになりません。既存の接続の期限を変更する機能はないため、無期限へ切り替える場合は新しく発行してください。

発行した接続は同じ画面で権限を変更・停止できます。停止すると、その後の取得要求は拒否されます。Cloudflare と通信できない場合も Hub 側は先に停止し、画面から Cloudflare 側の停止を再確認できます。AI にすでに渡した情報は回収されません。

読み取り API と、AI を使う端末で動かす MCP 接続プログラムを利用します。自動収集のスケジュール、過去の全記録を残すアーカイブ、削除・編集の完全な同期は未対応です。記録は Hub に残っている範囲を参照します。

接続後は、AI に「参照できる圃場を一覧にして」と依頼し、対象を選んで「この圃場の先週のメモと添付画像を確認して」「保存済みカメラ画像を日付で比較して」のように期間と目的を伝えます。写真の分析には、画像の取得結果に対応した AI アプリが必要です。

専用の認証情報を設定しても HTTP 401 が続く場合は、管理者に Hub の更新と参照権限を確認してもらってください。旧版には正常な機械認証を拒否する場合があります。人間用ログインへの切り替えは不要です。

管理者向けの設定、Codex への登録、取得例、接続できない場合の確認方法は [MCP 利用ガイド](../jp/MCP_USAGE.md)を参照してください。
