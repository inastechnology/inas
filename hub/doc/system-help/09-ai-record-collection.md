# AI に記録と写真を参照させる

専用の読み取り機能を含む Hub へ更新し、管理者が接続を設定すると、外部の AI から許可された圃場のメモ（note）、日々の記録、記録に添付した画像、保存済みのカメラ画像を参照できます。期間やキーワードで記録を絞り込み、必要な写真を確認できます。

管理者は、参照を許可する圃場と「記録」「画像」の範囲を指定します。収集用の接続では、機器の更新、設定変更、記録の追加・削除はできません。カメラ画像は保存済みの写真で、AI の取得要求による新しい撮影は行いません。

人間用の Cloudflare Access ログインを AI に代行したり、ログイン Cookie・認証コードを渡したりする必要はありません。専用の機械認証で接続します。AI アプリへ接続すると、呼び出した範囲の本文や写真がそのアプリへ渡ります。

現在用意されているのは読み取り API と、AI を使う端末で動かす MCP 接続プログラムです。Hub 画面からの接続設定、自動収集のスケジュール、過去の全記録を残すアーカイブ、削除・編集の完全な同期は未対応です。記録は Hub に残っている範囲を参照します。

接続後は、AI に「参照できる圃場を一覧にして」と依頼し、対象を選んで「この圃場の先週のメモと添付画像を確認して」「保存済みカメラ画像を日付で比較して」のように期間と目的を伝えます。写真の分析には、画像の取得結果に対応した AI アプリが必要です。

管理者向けの設定、Codex への登録、取得例、接続できない場合の確認方法は [MCP 利用ガイド](../jp/MCP_USAGE.md)を参照してください。
