# FGT：土壌水分の判定元を選んで予約潅水を見送る

個別センサー・平均の選択と、値を読めないときに潅水する動作には、対応する Hub と
**FGT ファームウェア 0.4.0 以降**が必要です。0.3.0 は「最初の有効なセンサーで判定し、
読取エラー時は見送る」動作でした。機器を更新し、最初の状態受信を待ってから設定を送信します。

## 設定方法

1. FGT の機器詳細で「動作設定」を開きます。
2. 「土壌水分による予約見送り」で、見送り機能を有効にします。
3. 「判定に使う土壌水分」から、名前と設置場所を確認して土壌水分計を選びます。
   「有効なセンサーすべての平均」も選べます。「自動」は従来どおり登録順で最初の有効な1台です。
4. 「見送るしきい値」を0〜100%の整数で指定し、設定を保存して機器へ送信します。

選択欄の横に対象の名前・場所・最後に届いた値・受信時刻を表示します。
平均を選ぶと、平均値に加えて計算対象の全台とそれぞれの値を確認できます。
例えば44%と76%の2台なら平均は60%です。しきい値60%ではその回を見送ります。
初期表示の40%は作物に適した値を保証するものではありません。現地の実測で調整してください。

「この測定値なら…」は、最後に届いた値と編集中のしきい値を比較した目安です。
実際の予約は、開始直前に選んだ対象を測り直して判断します。
「機器で確認済み」が出るまでは、機器に反映されたとは限りません。
測定一覧の目印も、反映待ちか、機器で確認済みかを区別します。

## 平均の対象と読取エラー

平均の対象は、このFGTで有効な土壌水分計すべてです。停止中のセンサー、光センサー、
別の機器の値は含めません。対象が1台ならその値を使います。

**選択した値を読めないときは、水分条件では見送らず予約どおり潅水します。**
平均の対象のどれかを読めないときも同じです。読めた台だけで平均は作りません。
個別指定したセンサーを外した場合も、他のセンサーへ勝手に切り替えません。
ポンプ出力や運転履歴などの異常時に停止する保護は引き続き働きます。

## 前回の判断を確認する

「前回の予約で使った値と判断」を開くと、そのときの判定元・水分値・しきい値・結果を確認できます。
読めなかった場合は「取得できず」と表示します。判断記録がまだ届いていない場合も明示します。
水分条件を通過した表示だけでは、ポンプ運転の完了を意味しません。運転履歴も確認してください。

しきい値以上で見送った回は、給水・液肥づくり・潅水の全工程を動かしません。
同じ予約を後から再実行せず、次の予約時刻に再判定します。

## 現在の機能の範囲

現在選べるのは、個別の1台・有効な全台の平均・従来の自動選択です。
一部のセンサーだけを組み合わせた平均、雨予報による見送り、運転途中の水分による停止は対象外です。
「土壌水分の未到達チェック」は別の通知機能で、その到達判定値や対象選択はこの設定へ反映されません。
