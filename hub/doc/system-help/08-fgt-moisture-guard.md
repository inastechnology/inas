# FGT：土が湿っているときに予約潅水を見送る

対応する Hub と **FGT ファームウェア 0.3.0 以降**で使えます。
Hub の設定保存だけでは旧ファームウェアの動作は変わりません。
機器の更新を済ませ、設定を受信したことを確認してから使ってください。

## 設定方法

1. 対象の FGT の機器詳細で「動作設定」を開きます。
2. 「ポンプの時間設定」の「土が湿っているときは予約運転を見送る」を有効にします。
3. 「予約運転を見送る土壌水分（この値以上）」を 0〜100% の整数で設定して保存し、機器へ送信します。

初期状態は無効です。例えば 60% に設定すると、予約運転の直前に測った値が
60%以上ならその回を見送り、60%未満なら設定した運転を始めます。
初期表示の40%や例の60%は作物に適した値を保証するものではありません。
現地の土の状態とセンサーの実測値を確認して設定してください。

## 見送る範囲とセンサーエラー

給水・液肥づくり・潅水を含む予約全体を見送ります。
時間指定運転とレシピ運転の両方に適用し、見送った予約を後から再実行しません。
次の予約時刻に改めて判断します。

FGT 本体に登録した順で最初の有効な土壌水分計を使います。
本体にセンサーの登録がなければ、動作設定の土壌水分計を使います。
複数台の平均や、別の機器の土壌水分は使いません。
センサーが無効・未接続・読取エラーの場合も、その回は見送ります。
予想外に潅水されないときは、土壌水分計の接続と測定状態を確認してください。

運転履歴の理由 `soil_moisture_high` は「土が十分湿っているため見送り」、
`soil_moisture_unavailable` は「土壌水分を読めないため見送り」です。
診断データには、判定に使った水分値と閾値も記録されます。

## 現在の機能の範囲

現在は開始前の水分値で予約を見送ります。雨予報だけによる見送り、
運転途中の水分値による停止、センサーごとの潅水先の切り替えはこの機能に含まれません。
「土壌水分の未到達チェック」は別の通知機能で、その到達判定値はこの設定へ反映されません。

詳細は [FGT の設定・状態仕様](../../../client-devices/fertigation-device/docs/mqtt_contract.md)、
通知機能は [土壌水分の未到達チェック](07-post-watering-moisture-alerts.md)を参照してください。
