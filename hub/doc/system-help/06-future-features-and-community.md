# 将来機能とコミュニティ提案

## 将来機能の確認

INASでは、検討中の機能を `FUT-nnn` という番号付きの将来機能一覧で管理します。一覧には、解決したい問題、現在の検討状態、詳しい仕様へのリンクがあります。

状態の意味は次のとおりです。

- 「構想」: 目的は記録されていますが、詳細仕様は未確定です。
- 「仕様あり」: レビューできる仕様はありますが、まだ利用可能とは限りません。
- 「一部提供」: 基盤や一部機能は利用できますが、記載された全体は未完成です。
- 「条件待ち」: 安全、セキュリティ、法務、外部許諾、現地検証などが必要です。
- 「提供済み」: 完了条件を満たし、利用できることを確認済みです。

「仕様あり」を「現在使える」と読み替えないでください。現在の操作方法を知りたい場合は、機能一覧ではなく各画面のシステムヘルプを確認します。

## 点滴潅水で検討していること

`FUT-001` では、次の三つを別の作業として検討しています。

1. 点滴チューブの上流、中央、末端で、点滴口を1穴ずつ採水して吐出量を校正する。
2. 作物、生育段階、天候、培地、校正流量から、通常潅水の量、回数、秒数を提案する。
3. 排液ECを確認しながら、真水を短いパルスで与えて培地の肥料塩類を減らす「培地リセット」を行う。

これは将来機能です。現在設定されている潅水秒数を、作物に適した水量や培地リセット量と自動的にみなしたり、既存の機器設定を自動変更したりしません。

土壌水分だけでは肥料塩類の蓄積を判断できません。培地リセットには、排水できる設備と、手持ちEC計または対応センサーによる排液EC確認が必要です。

## コミュニティから提案する

現段階では、利用者から伺った内容をmaintainerが確認し、将来機能一覧へ手作業で登録します。将来はHubまたは公開サイトから提案し、補足質問、重複整理、公開レビュー、状態変更の通知を受けられる仕組みを検討しています。

提案では次を教えてください。

- 現在困っていること
- できるようになってほしいこと
- 作物、作型、設備など公開可能な前提
- 現在の代替方法
- 計測結果や参考資料
- 失敗した場合に心配なこと

提案者名の公開は任意で、既定は匿名の「利用者提案」です。メールアドレス、住所、正確な圃場位置、APIキー、service token、非公開のdevice IDや写真は提案本文へ入れないでください。

## 支持数と採用判断

「同じことで困っている」という利用者の声は優先度を考える材料になります。ただし、支持数だけで自動採用しません。潅水、施肥、農薬、OTA、実機出力などは、安全性、公的資料、現地測定、互換性、保守負担を確認します。

提案の採用と、提出されたコードやExtensionの採用も別の判断です。コミュニティ提案を送ることは、HubのDB、MQTT、機器操作、ネットワーク、ファイル、秘密値への権限を付与するものではありません。

## 栽培相談との違い

このシステムヘルプは、将来機能の状態や提案方法を説明します。イチゴの具体的な潅水量、施肥量、農薬選定など、個別の栽培判断は対象作物の「この作物について質問」を使用してください。
