# 土壌水分の未到達チェック

## 現在できること

選択した土壌水分センサーが、直近N日間に設定した水分量へ到達していなければDiscordへ通知できます。Nは1〜14日の整数で設定できます。潅水機の実行通知には依存しないため、予約潅水、手動潅水、降雨を含めて根域の水分が一定期間回復していない状態を確認できます。

設定する内容はセンサーごとに次の3項目です。

- 判定に使う土壌水分センサー1台
- 監視期間1〜14日
- 到達してほしい土壌水分率

監視期間内に設定値以上が1回でも記録された場合に「到達」とみなします。潅水を開始するための乾燥しきい値とは別の設定で、この機能は潅水量、潅水時間、機器のRuntime Configを変更しません。

以前の「潅水後の水分チェック」で保存した条件は、選択済みセンサー、最低水分率、有効状態を引き継ぎ、監視期間3日の条件へ自動で移行します。以前選択していた潅水機は新しい判定には使用しません。

## 設定ウィザードを開く

対象圃場を開き、「環境・設備」→「土壌水分の未到達チェック」を確認します。圃場に配置された土壌水分センサーごとに、未設定・監視中・未到達・判定準備中・停止中、現在値、監視期間、到達判定値、最後に到達した時刻、Discord準備状態をカードで表示します。

管理者はカードの「通知条件を設定」または「通知条件を確認・変更」からウィザードを開けます。アプリ設定の「通知」や、SOI、ENV、WTR、WRS、FGTの機器詳細からも開けます。保存またはキャンセル後は、開いた圃場の「環境・設備」へ戻れます。

ウィザードでは、最初に判定センサーを選び、次に監視期間と到達判定値を設定します。グラフは設定した監視期間と同じN日分へ切り替わり、最新・最小・最大値、測定件数を確認できます。複数のセンサーがある場合は、設置場所と推移を見比べて、潅水対象の根域を代表する1台を選んでください。

「この水分未到達チェックを使用する」をOFFにすると、センサー、監視期間、判定値を残したまま通知判定を停止できます。保存済みカードから条件の変更と削除もできます。

Discord通知を受け取るには、Webhookが設定済みで、「すべてのDiscord通知」がONである必要があります。通知カードから判定センサーの現在値・履歴を開けます。通知カードの表示方針は[Discord通知設計](../../../docs/jp/DISCORD_NOTIFICATION_DESIGN.md)を参照してください。

## 判定と再通知

Hubはセンサーの測定受信時と、およそ30分ごとの定期確認でローリング期間を評価します。

- 直近N日間に設定値以上が1回でもあれば、到達済みとして通知しません。
- 設定値以上が1回もなく、測定履歴が期間を十分に覆っていれば通知します。
- 未到達が続く場合は24時間ごとに再通知します。
- 通知後に設定値以上を1回確認すると、未到達状態を自動で解除します。
- 履歴が少ない、期間の前半が欠けている、最新測定が古い場合は「判定準備中」とし、水分不足通知を送りません。
- センサーが停止中または測定値を取得できない場合も、水分不足とは判定しません。

## 現在行わないこと

現在は、複数センサーの平均・多数決、上限超過の通知、季節による監視期間の自動切り替え、通知に応じた自動追加潅水は行いません。センサーデータ未受信は水分未到達と区別しますが、この条件から別のDiscord通知は送りません。

Discord通知だけで水不足や設備故障と断定せず、通知時は潅水記録、降雨、タンク、ポンプ、配管、センサー位置、実際の土の状態を確認してください。潅水設備が実行後に水分を上げられたかを調べる設備診断は、この未到達通知とは別の機能です。
