# 潅水後の土壌水分チェック

## 現在できること

潅水機が実際に潅水した後、選択した土壌水分センサーの測定値が設定した最低水分率に届いたかをHubが確認できます。下限未満の場合は、同じ潅水につき1回だけDiscordへ通知します。

設定できる内容は潅水機ごとに次の3項目です。

- 潅水を確認する機器
- 判定に使う土壌水分センサー1台
- 潅水後に到達してほしい最低水分率

潅水を開始するための乾燥しきい値とは別の設定です。この機能は潅水量、潅水時間、機器のRuntime Configを変更しません。

## 設定ウィザードを開く

対象圃場を開き、「環境・設備」→「潅水後の水分チェック」を確認します。ここには圃場に直接配置された潅水機に加え、圃場内の判定センサーを使う潅水機もカードで並びます。未設定・監視中・停止中、判定センサー、センサー現在値、潅水後の最低水分率、Discord準備状態をまとめて表示します。管理者は各カードの「通知条件を設定」または「通知条件を確認・変更」からウィザードを開けます。保存またはキャンセル後は同じ圃場の「環境・設備」へ戻れます。

アプリ設定の「通知」や、WTR、WRS、FGTの機器詳細からも設定ウィザードを開けます。

ウィザードでは、最初に潅水機、次に判定センサー、最後に最低水分率を選びます。センサーを選ぶと、そのセンサーの直近3日分の土壌水分推移、最新・最小・最大値、測定件数を確認できます。複数のセンサーがある場合は、推移と設置場所を見比べて、潅水対象の根域を代表する位置のセンサーを1台選んでください。「この潅水後チェックを使用する」をOFFにすると、組み合わせと下限を残したまま判定を停止できます。

保存済みカードの「通知条件を確認・変更」から開くと、現在のセンサー、最低水分率、使用状態が選択された編集画面になります。「変更を保存」で上書きできます。条件を完全に取り除く場合は、画面下部の「通知条件を削除」を使います。削除すると、まだ判定待ちの潅水後チェックも同時に取り消されます。

Discord通知を受け取るには、Webhookが設定済みで、「すべてのDiscord通知」がONである必要があります。通知カードからは判定に使ったセンサーの現在値・履歴を開けます。通知カードの表示方針は[Discord通知設計](../../../docs/jp/DISCORD_NOTIFICATION_DESIGN.md)を参照してください。

## 判定のタイミング

WRSが潅水後の測定値を同じ状態報告に含めた場合は、その値を判定します。それ以外は、潅水の実行をHubが確認した後、選択センサーから最初に届いた有効な土壌水分値を判定します。センサーがスリープ中なら、次回通信まで待ちます。

下限と同じ、または上回った場合は通知しません。下限未満だった場合も、次の潅水が実行されるまでは同じ通知を繰り返しません。

## 現在行わないこと

現在は、測定値が届かないこと自体の通知、上限超過の通知、複数センサーの平均・多数決、下限に応じた自動追加潅水は行いません。Discord通知だけで水が根域へ届いたと断定せず、初回設定時と異常通知時はタンク、ポンプ、配管、センサー位置、実際の土の状態を確認してください。
