# 個人設定、アプリ設定、権限

## 個人設定

個人設定は各利用者が変更できます。タイムゾーン、日付形式、栽培アドバイスの説明レベルなどを利用者のメールアドレス単位で保存します。栽培アドバイスは「初心者」「標準」「プロ」から選べます。Hub の表示言語は日本語固定で、他言語が必要な場合はブラウザの翻訳機能を使用します。

## アプリ設定

アプリ設定は Hub 全体へ影響する管理者向け設定です。ヘッダーのアプリ設定から、AI の有効・無効、Base URL、モデル、接続確認、画像解析、栽培計画の設定などを管理します。AI APIキーは画面へ再表示されず、値の登録や変更はサーバー側の設定手順で行います。

現在、AIカテゴリの「テキスト・栽培計画」にある「接続先とモデル特性を調整（上級者向け）」から、モデルの「考える深さ」を設定できます。ここで選んだ値はInstagram投稿文、栽培カレンダー、目標レンジ、質問回答に適用されます。`xhigh` は対応モデルでのみ利用でき、深くすると処理時間や使用トークンが増える場合があります。保存前に「接続を確認」で選択したモデルが値を受け付けることを確認してください。画像解析には、画像側の「考える深さ」が別に適用されます。

現在、Instagramカテゴリの「Instagramへの自動投稿を一時停止する」を有効にして保存すると、それ以降の設定時刻では投稿処理を開始しません。撮影済み画像、投稿元カメラ、前回投稿の情報は保持されます。チェックを外して保存すると、次の設定時刻から自動投稿を再開します。保存時点ですでに投稿処理が始まっている場合、その1件は完了することがあります。

現在、Instagramカテゴリの「センサーグラフ投稿」を有効にすると、直近3日間で取得できた土壌水分、日射量またはPAR、気温または地温を1時間単位で平均し、縦長4:5のグラフ画像としてInstagramフィードへ毎日投稿できます。「グラフ投稿時刻」はReelの投稿時刻とは別に設定でき、既定はHubのタイムゾーンで20:00です。投稿ごとに注目する測定項目を切り替え、「最初と最新」「3日間の振れ幅」「最新値と平均」の切り口も循環します。画像上部にはAIが生成した温かみのある10文字以内の感想を表示し、直近7投稿と似た感想や生成できなかった感想は、当日の測定項目に沿う定型文へ差し替えます。本文には当日の切り口に対応する実測値を記載します。「グラフ元センサー」は自動選択が既定で、項目ごとに有効データが最も多い機器を選びます。データがない日は投稿を見送ります。全自動投稿の一時停止はReelとセンサーグラフの両方に適用されます。

普段の確認と設定は、対象圃場の「環境・設備」にある「土壌水分の未到達チェック」を使います。圃場に配置された土壌水分センサーごとに、未設定・監視中・未到達・判定準備中・停止中、現在値、監視期間、到達判定値をカードでまとめて確認できます。管理者は各カードから設定ウィザードを開き、設定した1〜14日分の推移を見ながら条件を変更または削除できます。アプリ設定の通知カテゴリからも同じウィザードを開けます。現在の判定範囲は[土壌水分の未到達チェック](07-post-watering-moisture-alerts.md)を参照してください。

圃場設定に AI 設定はありません。AI は圃場ごとの設定ではなく Hub 全体のアプリ設定です。

## 権限

- reader: 情報を閲覧できます。
- operator: 通常の運用操作や記録を行えます。
- admin: アプリ設定や管理操作を行えます。

操作ボタンが表示されない、または無効な場合は、現在の利用者の権限と画面に表示される無効理由を確認してください。Cloudflare 経由の利用者は Cloudflare Access の許可と Hub 内のユーザー登録の両方が必要です。

Cloudflare Access のログイン画面と公開 Hub 画面は、人間の利用者向けです。現在、AI エージェントによる遠隔管理には専用の Operations API と機械用の認証情報を使います。AI エージェントのために代理ログインしたり、ログイン Cookie や認証コードを渡したりする必要はありません。対応する操作と設定は [Operations クライアントの説明](../../scripts/operations/README.md)を参照してください。

圃場の記録や写真を AI に参照させる場合は、機器操作とは別の読み取り権限を設定します。利用できる範囲と未対応の機能は [AI に記録と写真を参照させる](09-ai-record-collection.md)を参照してください。
