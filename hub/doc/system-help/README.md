# INAS Hub システムヘルプ

このフォルダーは Hub のシステムヘルプ検索で利用する日本語文書です。栽培方法そのものではなく、Hub の画面、登録、記録、設定、機器管理の使い方を説明します。

質問例:

- 圃場を追加するには？
- デバイスの設定画面はどこ？
- 栽培カレンダーで作業完了を記録するには？
- AI の接続設定は誰が変更できる？
- デバイスが表示されないときは何を確認する？
- 点滴潅水の校正や培地リセットは現在使える？
- 潅水後の土壌水分が低いときにDiscordへ知らせるには？
- 将来機能をコミュニティへ提案するには？

栽培、施肥、防除、病害虫など農作業上の判断は、作物ごとの「栽培相談」を使用してください。
