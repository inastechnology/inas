# 設置ビューと機器

## 機器を圃場へ割り当てる

圃場詳細の設置プレビューにある鉛筆アイコンから設置エディタを開きます。ハウス、露地、畝、鉢、設備などを配置し、機器を実際の設置場所へ割り当てます。水やり機器には潅水対象、センサーには計測対象も指定します。

機器メタデータの古い「場所」ではなく、設置ビューの割り当てが正式な設置場所です。複数の人が同時に編集した場合は無言で上書きせず、最新版との比較・統合画面が表示されます。

## 機器詳細のタブ

- 「概要」: 現在状態、設置場所、通信、設定受信、時刻同期、出力先を確認します。
- 「計測・稼働」: 気温、湿度、土壌水分、EC、pH、PAR、潅水などの履歴を確認します。
- 「動作設定」: 表示名、水やり予約、出力先、センサー調整などを変更します。
- 「ファームウェア」: 現在バージョン、firmware.bin の登録、更新予約、OTA履歴を確認します。
- 「保守・診断」: 承認、停止、廃止、診断情報を確認します。

日常的な設定は「動作設定」を使います。NTP、デバッグ、raw JSON などは上級者向けまたは保守・診断にあります。

## 水やり機器の設定

水やり機器では「設備をつなぐ」「水やりを決める」「センサーを合わせる」の順に設定します。「下書きを保存」は Hub に設定を保存する操作で、「組み立てた設定を機器へ送る」は機器へ反映する操作です。下書きを保存しただけでは機器へ反映されません。

## ファームウェア更新

機器詳細の「ファームウェア」タブを開き、firmware.bin をドラッグ＆ドロップして登録します。登録後に対象バージョンと更新予約を確認します。ファームウェア操作を「動作設定」や「保守・診断」から探す必要はありません。
