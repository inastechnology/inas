# 設置ビューと機器

## 機器を圃場へ割り当てる

圃場詳細の設置プレビューにある鉛筆アイコンから設置エディタを開きます。ハウス、露地、畝、鉢、設備などを配置し、機器を実際の設置場所へ割り当てます。水やり機器には潅水対象、センサーには計測対象も指定します。

機器メタデータの古い「場所」ではなく、設置ビューの割り当てが正式な設置場所です。同じ圃場を開いている人と画面数はCanvas上部の「共同編集」から確認できます。相手が選んでいる配置物には名前付きの色枠が表示されます。

相手が保存すると、編集中の項目と重ならない変更は自動で取り込みます。同じ項目を双方が変更した場合だけ、最新版との比較・統合画面を表示します。共同編集の接続が一時的に切れても入力は保持され、そのまま編集を続けられます。

## 機器詳細のタブ

- 「概要」: 現在状態、設置場所、通信、設定受信、時刻同期、出力先を確認します。
- 「計測・稼働」: 気温、湿度、土壌水分、EC、pH、PAR、潅水などの履歴を確認します。
- 「動作設定」: 表示名、水やり予約、出力先、センサー調整などを変更します。
- 「ファームウェア」: 現在バージョン、firmware.bin または INASリリースモジュール（.inasfw）の登録、更新予約、OTA履歴を確認します。
- 「保守・管理」: 承認、停止、廃止、接続履歴、管理者向け情報を確認します。通信で困ったときは、見出し右の「？」を開きます。

日常的な設定は「動作設定」を使います。NTP、デバッグ、raw JSON などは上級者向けまたは保守・管理にあります。

## 水やり機器の設定

水やり機器では「設備をつなぐ」「水やりを決める」「センサーを合わせる」の順に設定します。「下書きを保存」は Hub に設定を保存する操作で、「組み立てた設定を機器へ送る」は機器へ反映する操作です。下書きを保存しただけでは機器へ反映されません。

## FGTの予約と潅水設定

FGT（液肥づくり・潅水装置）の予約運転は常に有効です。利用者が機器全体の予約運転をON/OFFする項目はありません。個別の予約は「この予約を使う」で利用・停止を選べます。

有効な予約があるのに潅水ポンプのON時間または繰り返し回数が0の場合、その予約では潅水されません。Hubは概要と動作設定に「設定不足」を表示し、下書き保存または機器への送信前にも警告します。通常の潅水を予約する場合は「潅水ポンプ ON時間」と「潅水ポンプ 繰り返し」を1以上に設定してください。

画面の「Hub登録：利用中」は、機器がHubに登録され設定を送れる状態を表します。予約内容が実行可能かどうかは、別に表示される「予約運転」を確認してください。

## ファームウェア更新

機器詳細の「ファームウェア」タブを開き、firmware.bin または INASリリースモジュール（.inasfw）をドラッグ＆ドロップして登録します。.inasfw を選んだ場合、Hubは中の firmware.bin だけを取り出して登録し、bootloaderや初期設定領域は使用しません。登録後に対象バージョンと更新予約を確認します。ファームウェア操作を「動作設定」や「保守・管理」から探す必要はありません。
