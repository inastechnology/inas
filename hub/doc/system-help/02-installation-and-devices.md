# 設置ビューと機器

## 機器を圃場へ割り当てる

圃場詳細の設置プレビューにある鉛筆アイコンから設置エディタを開きます。ハウス、露地、畝、鉢、設備などを配置し、機器を実際の設置場所へ割り当てます。水やり機器には潅水対象、センサーには計測対象も指定します。

機器メタデータの古い「場所」ではなく、設置ビューの割り当てが正式な設置場所です。同じ圃場を開いている人と画面数はCanvas上部の「共同編集」から確認できます。相手が選んでいる配置物には名前付きの色枠が表示されます。

相手が保存すると、編集中の項目と重ならない変更は自動で取り込みます。同じ項目を双方が変更した場合だけ、最新版との比較・統合画面を表示します。共同編集の接続が一時的に切れても入力は保持され、そのまま編集を続けられます。

## 機器詳細のタブ

- 「概要」: 現在状態、設置場所、通信、設定受信、時刻同期、出力先を確認します。
- 「計測・稼働」: 気温、湿度、土壌水分、EC、pH、PAR、潅水などの履歴を確認します。
- 「動作設定」: 表示名、水やり予約、出力先、センサー調整などを変更します。
- 「ファームウェア」: 現在バージョン、INAS更新ファイル（.inasfw）の登録、更新予約、OTA履歴を確認します。
- 「保守・管理」: 承認、停止、廃止、接続履歴、管理者向け情報を確認します。通信で困ったときは、見出し右の「？」を開きます。

日常的な設定は「動作設定」を使います。NTP、デバッグ、raw JSON などは上級者向けまたは保守・管理にあります。

## 水やり機器の設定

水やり機器では「設備をつなぐ」「水やりを決める」「センサーを合わせる」の順に設定します。「下書きを保存」は Hub に設定を保存する操作で、「組み立てた設定を機器へ送る」は機器へ反映する操作です。下書きを保存しただけでは機器へ反映されません。

## FGTの予約と潅水設定

FGT（液肥づくり・潅水装置）の予約運転は常に有効です。利用者が機器全体の予約運転をON/OFFする項目はありません。個別の予約は「この予約を使う」で利用・停止を選べます。

各ポンプは「使用する」で有効・無効を選びます。無効にすると繰り返し0回として保存し、ON/OFF時間の設定欄を隠します。時間値は保持されるため、再度有効にすると続きから設定できます。有効時の値域はON時間1〜1800秒、OFF時間0〜1800秒、繰り返し1〜99回です。

有効な予約でA液ポンプなどが設定されていても、潅水ポンプが無効またはON時間0秒なら、植物への送水は行われません。A液ポンプなどの有効な出力は設定どおり動作します。Hubはこの状態を「設定不足」として表示し、下書き保存または機器への送信前にも警告します。

画面の「Hub登録：利用中」は、機器がHubに登録され設定を送れる状態を表します。予約内容が実行可能かどうかは、別に表示される「予約運転」を確認してください。

## FGTの潅水履歴

現在、FGTの機器詳細で「現在値・履歴」を開くと、予約運転を実行した日時と実行時間を「潅水推移」と「直近の灌水記録」で確認できます。時間指定運転では、機器が報告した一連の運転時間を使うため、流量のmL校正をしていなくても履歴を確認できます。待機しただけの定期通信は潅水記録に含めません。

「今回の給水量推移」は流量計から受信したmL値です。流量校正をしていない場合、このグラフだけで実行有無を判断せず、潅水推移と直近の灌水記録を確認してください。

## FGTの土壌センサー値

現在のFGTが対応する土壌センサー値は「土壌水分」「地温」「土壌EC」の3項目です。pH、窒素、リン、カリウムには対応していないため、FGTの計測画面には表示せず、旧ファームウェアから届いた値も計測・栽培判断には使用しません。

FGTファームウェア0.2.1以降は対応する3項目だけを取得・送信します。0.2.0以前で表示されたpHやN/P/Kは、非対応レジスタを7項目センサー用に解釈した値であり、実測値として利用できません。

pHやN/P/Kに対応する別の土壌センサーを将来利用する場合は、機種別センサープロファイルを追加してから提供します。現在は未対応です。

## ファームウェア更新

機器詳細の「ファームウェア」タブを開き、INAS更新ファイル（.inasfw）をドラッグ＆ドロップします。ファイル情報の読み取りに成功すると「登録する」が押せるようになります。Hubは更新に必要なアプリ本体領域だけを取り出し、bootloaderや初期設定領域は使用しません。

登録が完了してもページは移動しません。同じ画面の「登録済み更新ファイル」が自動で開き、新しいバージョンが一覧と更新予約の候補へ即時に追加されます。画面を手動で再読み込みする必要はありません。ファームウェア操作を「動作設定」や「保守・管理」から探す必要もありません。
