# 画面の見方と圃場の登録

## 最初の画面

Hub の最初の画面は圃場一覧です。圃場名や所在地で検索し、対象の圃場を選ぶと圃場詳細へ進みます。すべての機器を最初の画面へ並べる構成ではありません。

## 圃場を追加する

圃場一覧の「＋ 圃場を追加」を押し、名前、都道府県、市区町村、設置環境を入力して保存します。ここでは作物、品種、畝、デバイス、目標値は登録しません。

作物は圃場を作成した後、設置ビューで鉢、畝、プランターなどの培地を配置し、その培地へ定植します。機器も圃場作成後に設置ビューから配置場所や対象を割り当てます。

## 圃場詳細のタブ

- 「概要」: 現在値、目標範囲との比較、次の判断候補を確認します。
- 「環境・設備」: 圃場内の土壌水分センサーごとの未到達通知条件、圃場全体や場所ごとの時系列グラフ、設置機器を確認します。管理者は通知条件カードから設定ウィザードを開けます。
- 「栽培」: 定植した作物、年間栽培カレンダー、作物ごとの経過を確認します。
- 「記録」: 月間カレンダーと手入力記録を扱います。デバイスがなくても利用できます。
- 「設定」: 圃場名、所在地、設置環境を変更します。

現在、同じ測定項目を複数のセンサーから取得できる場合、概要の現在値には各センサーの最新の有効値から求めた中央値を表示します。センサーが偶数本の場合は、中央2値の平均です。停止中、読取エラー、値がないセンサーは計算に含めません。目標範囲との比較と作業TODOの判断にも同じ中央値を使います。カード下部の「○センサーの中央値」で計算に使った本数を確認でき、個々の値は「環境・設備」タブまたは機器詳細で確認できます。

現在値がない測定項目は表示されません。現在値はあるが作物の目標範囲が設定されていない場合は「目標未設定」と表示されます。
