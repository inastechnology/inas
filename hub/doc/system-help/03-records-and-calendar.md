# 記録と年間栽培カレンダー

## 圃場の記録

圃場詳細の「記録」タブでは、月間カレンダーから定植、作業実績、観察、判断記録、デバイス自動取得件数を確認できます。手入力はデバイスが0台でも利用できます。

記録フォームで潅水時間、EC、pH、作物状態など必要な項目を検索して追加し、値と評価を入力して保存します。同じ日のデバイス値がある場合は、機器名、値、単位、取得時刻も参考情報として表示されます。画像を添付して振り返ることもできます。

## 年間栽培カレンダー

圃場詳細の「栽培」タブで作物を選び、年間カレンダーを開きます。カレンダーは定植単位で管理されるため、同じ圃場でも作物や培地ごとに計画と履歴が分かれます。

作業カードには実施候補期間、優先度、理由、開始判断、見送り条件、手順、完了確認が表示されます。作業を選び、「開始」「完了」「延期」「見送り」など現在の判断を記録します。完了時には実施日と結果を保存し、反復作業であれば保存済みの規則から次回候補が作成されます。

## 栽培相談との違い

年間カレンダーの「この作物について質問」は、選択中の作物、圃場、計画、施肥履歴、過去の相談を参照する栽培専用チャットです。Hub の画面操作や設定場所を知りたい場合はシステムヘルプを使用します。
