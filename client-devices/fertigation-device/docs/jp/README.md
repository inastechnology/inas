# FGT 液肥づくり・潅水装置 設計概要

FGT は WRS を土台にした液肥作成・潅水デバイスで、device kind は
`FGT` とする。

## 現在のハードウェア状態

FGT専用基板はまだ製造されておらず、実在しない。現在のF/Wと初回動作確認では、
XIAO ESP32-C6へ個別のMOSFETスイッチとRS485トランシーバを直接配線する
最小構成を使用する。現在の正しいPIN配置は
[最小構成配線](minimal_wiring.md)を参照する。

`hardware/esp32c6-solar-controller`以下のKiCad回路・基板・筐体データは、
将来の専用基板に向けた開発中の設計資料である。現時点では製造・実装・接続
されておらず、現在のFGTの配線、F/Wプロファイル、動作確認には使用しない。

現在の最小構成では、XIAO ESP32-C6のGPIOから次の5つの機材を制御する。

- 原水を入れる電磁弁またはポンプ
- A液用の12V蠕動ポンプ
- B液用の12V蠕動ポンプ
- タンク内を循環させる12Vブラシレス攪拌ポンプ
- 植物へ送る12V潅水ポンプ

## 1回の運転

通常の液肥レシピ運転は次の順序で行う。

1. タンクが空で、漏水・非常停止・I/O異常がないことを確認する。
2. 原水を1.25 L入れる。
3. 攪拌を始め、A液を校正済み時間だけ入れる。
4. A液を十分に攪拌してから、B液を入れる。A液とB液は同時に入れない。
5. 攪拌しながら原水を追加し、液肥バッチ用の水を合計4.5 Lにする。
6. 最終攪拌後、空検知まで植物へ潅水する。
7. 清水0.5 Lを入れて攪拌し、同じ潅水経路へ流してタンクと配管を洗う。

洗浄水も植物へ届くため、既定の総潅水水量は4.5 L + 0.5 L = 5.0 L
として計画する。A/B原液の少量は別に記録する。残液を理由に液肥全体を
無条件で薄めず、タンク勾配、吸込位置、空検知位置を調整して実測残量を
減らし、その残量と配管容量から洗浄水量を決める。

単純な潅水・動作確認では、時間指定運転を選べる。各出力のON時間、OFF時間、
繰り返し回数を設定し、出力番号順に1つずつ動かす。例えばA液ポンプだけを
120秒動かし、ほかの出力を0秒にできる。この運転は液肥レシピの給水、B液、
攪拌、潅水、洗浄工程を実行しない。

## 安全方針

以下はFGT製品として必要な安全要件である。現在の最小構成PIN配置には、流量、
液面、漏水、非常停止の専用入力がない。この段階では監視下の水だけの試験に
限定し、ポンプ12V電源を直接遮断できる外部非常停止を設ける。無人運転や液肥
投入は、必要な安全入力と停止処理を実装・検証するまで行わない。

- 起動、OTA、sleep、設定異常、I/O異常、漏水、非常停止、timeoutでは
  全出力をOFFにする。
- 液肥レシピ運転ではA液とB液を同時に動かさず、どちらの投入中も攪拌を
  必須にする。時間指定運転では出力を1つずつ動かし、同時運転しない。
- 給水中は流量が増えることを監視し、増えなければ停止する。
- 想定水量より早く満水になった場合は続行せず異常停止する。
- 停電やresetで中断したバッチは自動再開しない。タンクが安全に空である
  ことを確認し、Hubから明示的に復旧確認番号を更新するまで待機する。
- 新規flash直後およびFGT固有設定が届いていない状態は
  `fgt.enabled=false` とし、液肥を自動投入しない。

## 電源と配線の前提

電源は18650 6本の3S2P、3S BMS、12.6V CC/CVソーラー充電器を前提とする。
ポンプ始動電流を含めて安定させた12V系と、XIAO用5Vロジック電源を分ける。
A液・B液を含む現在のポンプはすべて12V系へ接続する。
初期の設計消費量は待機損失を含め5〜8 Wh/日とし、実機でスリープ電流、
各ポンプ電流、流量を測定して更新する。20Wパネルは日照が得られる場所での
基準であり、日陰設置では発電量を実測する。
